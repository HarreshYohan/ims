# IMS - Admin & Staff Application

This is the administrative interface for the Institute Management System. It handles staff management, student registrations, financial tracking, and system-wide analytics.

## Features
- Student & Staff Directory
- Transaction Management
- Academic Reporting
- System Settings & Logs

## Getting Started
1. Install dependencies: `npm install`
2. Start development server: `npm start`
3. Access at: `http://localhost:3000`

## Configuration
Update `.env` if the API is running on a different port:
`REACT_APP_API_URL=http://localhost:8083/api/v1`
