# IMS - Student & Tutor Portal

This is the learning portal for students and the dashboard for tutors. It focuses on academic progress, learning materials, and goal tracking.

## Features
- Student Dashboard (Grades, Progress)
- Tutor Dashboard (Subject Management)
- Learning Tools (Notes, Flashcards, Quizzes)
- Goal Tracking

## Getting Started
1. Install dependencies: `npm install`
2. Start development server: `npm start`
3. Access at: `http://localhost:3001`

## Configuration
Update `.env` if the API is running on a different port:
`REACT_APP_API_URL=http://localhost:8083/api/v1`
